### Ideas I've Put Out

- **Agent-Interface Doctrine** — The web is an interface built for humans. Agents reading HTML, CSS and JS pay a token tax that degrades accuracy. The fix is an agent-facing layer: linked Markdown, per-level indexes, progressive disclosure. The memory-graph plugin above is the reference implementation.
- **LCMP (Long-Term Context Management Protocol)** — AI memory that persists across sessions through the filesystem. [On Medium](https://medium.com/@timbiondollo)
- **Dynamic Domain Specialist Protocol** — A prompting structure for turning Claude into a specialized domain expert. [On Medium](https://medium.com/@timbiondollo)
- **Claude Skills Playbook** — Lifecycle for building, deploying and governing Skills at organization scale.
